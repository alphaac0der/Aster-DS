# Phosphor Icons Manifest

This directory contains curated SVG glyphs from [Phosphor Icons](https://phosphoricons.com/) used by the Aster Design System documentation portal and component blueprint renderer.

- **Creators:** Tobias Fried & Helena Zhang
- **License:** MIT License (see [LICENSE](LICENSE) or https://github.com/phosphor-icons/core/blob/main/LICENSE)
- **Format:** Regular weight SVGs with `viewBox="0 0 256 256"` and `fill="currentColor"`
- **Included Glyphs (23):** `sparkle`, `magnifying-glass`, `sliders`, `list`, `x`, `eye`, `eye-slash`, `warning-circle`, `arrow-right`, `tray`, `plugs`, `sun`, `moon`, `copy`, `check`, `play`, `code`, `caret-down`, `caret-up-down`, `caret-up`, `cube`, `palette`, `lightning`.
