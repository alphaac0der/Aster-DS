# Aster

Aster is a design system with two interfaces built from one source of truth:

- **Human-facing documentation** for designers, developers, and product teams.
- **Agent-facing specifications** for AI coding agents.

**Current stage:** project setup complete; discovery not yet started. No visual identity, tokens, components, or technical architecture have been decided.

## Where things are

| Path | Contents |
|---|---|
| `governance/` | Stable rules for how Aster is built: mission, user profile, Lydia's identity and principles, workflow and approval protocol |
| `records/DECISION-LOG.md` | Every consequential decision — proposed, approved, rejected, or superseded |
| `records/STATUS.md` | Current work package, progress, and next step |
| `AGENTS.md` | Entry point for AI agents working on this repository |

## How work happens

Lydia (the AI agent) proposes work packages; the founder approves them before implementation. See `governance/WORKFLOW.md`.

## Version control

Local Git only. No remote is configured and nothing is published.
