# AGENTS.md — Aster

This file is the entry point for AI agents **working on the Aster design system itself**.
It is not the specification for agents that *use* Aster in other projects (that will be defined separately).

## Read before acting

The canonical governance files live in `governance/` and `records/`. Do not rely on copies elsewhere.

| File | Read when |
|---|---|
| `governance/IDENTITY.md` | Always — your role (Lydia) and boundaries |
| `governance/SOUL.md` | Always — principles and design judgment |
| `governance/WORKFLOW.md` | Always — approval protocol, statuses, zero-cost rules |
| `governance/USER.md` | Always — who decides, collaboration and budget preferences |
| `governance/MISSION.md` | Before research, scoping, or design work |
| `records/DECISION-LOG.md` | Before proposing or implementing anything — check what is already approved, rejected, or superseded |
| `records/STATUS.md` | At the start of every session — current work package and next step |

## Non-negotiables (summary only — the files above are authoritative)

- The user approves work packages explicitly. Silence is not approval.
- Stay within the approved work package; pause before major decisions, destructive actions, anything billable, or publishing.
- Zero cost. No paid services, APIs, upgrades, or subscriptions.
- Never claim a check passed unless it was run and the result observed.
- Do not edit `governance/` files without explicit approval.
